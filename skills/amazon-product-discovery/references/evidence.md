# 证据口径与决策记录

## 记录单元

一条证据记录一个可检验主张：

`证据ID｜主张｜原值/短摘录｜来源URL｜检索日期｜原始日期/覆盖期｜站点/人群｜ASIN及规格/父子体/品牌/细分层级｜类型｜独立性与限制｜支持或反驳什么`

类型使用：平台公开原值、授权后台数据、第三方估计、用户描述、卖家/品牌主张、研究假设。抓取日期不是统计日期。找不到写「未获取」，冲突的原值保留两条并标记冲突，不自行挑较好看的值。

## 不能互换的字段

| 可得信号 | 正确使用 | 不允许的替代 |
| --- | --- | --- |
| Amazon 近月购买标签 | 原样保存文本、日期、商品层级，作为近期购买线索。 | 不填实际月销量；没有标签不记零。 |
| BSR、关键词排名 | 记录类目、站点和时间，用来观察相对变化。 | 不跨类目比体量，不用 BSR 套通用公式生成真实销量。 |
| 第三方销量/搜索量 | 标估计值与提供者、时间和算法口径（已知时）。 | 多家结果相近不等于多份独立实测。 |
| rating count / Review / 抽样评论 | 分开存评分人数、文字 Review 数、可见样本数及所述规格。 | 不把评分人数当文字 Review；不把父体总数灌给每个子体。 |
| 页面选项组合 | 记可见组合及所见范围。若可见数已超过上限，可支持超限。 | 可见数少不证明全变体少；不将颜色数直接当变体总数。 |
| 最早评论、索引或拍卖日期 | 只能证明该商品最迟当时已经存在；有同 ASIN 身份证据且早于时长截止日时可用于排除。 | 不能证明精确首次上架日，更不能凭 ASIN 字母推上架时间。 |
| POE / Brand Analytics | 按报表定义分别读词、细分、品牌或 ASIN。 | 不将细分总量当单品销量，不将本品牌漏斗当全市场。 |
| 搜索结果与集中度 | 先定义查询范围、去重单位和分母。货架出现占比与有销售数据的销量占比分开。 | 不把结果数量当供给总量；不把点击、销售和评论集中度混算。 |
| Google Trends | 同地区、时间范围和比较设置下的相对搜索兴趣。 | 不是绝对搜索量，不等于 Amazon 需求。 |
| 众筹、Etsy、eBay、TikTok、小红书 | 记录本平台实际指标、地区和激励条件，再独立验证目标站点。 | 支持额、点赞、广告表现和跨平台成交不转换成 Amazon 月销量。 |

## 评论与独立证据

- 去重按原始事实，不按域名数。转载、截图转录、同一评论多处出现算同一条；多个相似工具使用同一上游也不算独立证据。
- 低星抽样用来找问题，高星与相反反馈用于检验条件；写清采样方法、样本数、独立商品覆盖与时间。只对已采样内容报告频次，不外推缺陷率。
- “缺尺寸”可能是页面信息不全，“难安装”可能是柜型不匹配，“不耐用”可能涉及运输或使用方式；根因不明时给待验证原因，不直接承诺改款有效。
- 证据相互矛盾时，检查地区、规格、时间、促销和商品家族。无法解释且会改变结论时，降为待补证。

## 筛选与停止

将每条已确认规则判为「通过」「不符」「未获取」；三者不能合并为一个分数。只有各项硬门槛均有可比证据的对象才可作为通过门槛的候选，仍需人工最终审核。

明确不符写规则、观测值、阈值及证据；缺证写缺失字段、为何影响判断、最低补证动作。未确认的偏好、方法示例和网络文章阈值不参与硬淘汰。

查不到来源或工具失效时，不用 AI 填空；记录访问问题、已尝试的独立来源和仍可完成的研究。供应链、成本、知识产权和合规只能在取得证据后给研究判断，最终决策保留人工审核状态。
