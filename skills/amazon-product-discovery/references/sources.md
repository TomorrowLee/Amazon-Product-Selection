# 来源地图

本地图来自手册公开资料调研，整理日期为 2026-11-16。链接是研究入口；当前功能、权限、指标定义和规则在使用时重新打开核查。论坛经验和工具 README 不证明方法有普遍成功率。

| 方法/问题 | 优先入口 | 使用边界 |
| --- | --- | --- |
| 场景、凑合法、站外调研 | [知无不言需求先行](https://www.wearesellers.com/question/123662)、[卖家站外与供应链经验](https://www.wearesellers.com/question/90898)；再查目标用户的垂直论坛与 Reddit 原帖。 | 卖家方法用于设计研究；需求本身仍需目标买家证据。 |
| 关键词与细分 | [Amazon Seller Forums 的 niche 说明](https://sellercentral.amazon.com/seller-forums/discussions/t/681c4de8-ceaa-4042-b41f-dedd05662535)、[POE](https://sell.amazon.com/tools/product-opportunity-explorer)、[需求缺口](https://sellingpartners.aboutamazon.com/product-opportunity-explorer)、[Brand Analytics](https://sell.amazon.com/tools/amazon-brand-analytics)。 | 公开说明不等于已访问账户数据；实际工具需可用权限。 |
| 新品、排名、购买标签 | [BSR 与关键词排名讨论](https://sellercentral.amazon.com/seller-forums/discussions/t/5cd0156f-ecdd-48fa-86fe-6b6612b383f4)、[购买标签官方公告](https://sellercentral.amazon.com/seller-forums/discussions/t/732ded0cef8e8ee8c2a7caf832bc85f0)、[Keepa](https://keepa.com/)。 | 只按来源定义使用，不推定实际件数。 |
| 评论与商品层级 | [全球开店选品问答](https://globalselling.amazon.com/learn/faq)、[变体评论共享公告](https://sellercentral.amazon.com/seller-forums/discussions/t/a572986d-9bb1-4e91-a53f-41c575874dd7)。 | 旧规则和旧评论可能不适用于新规格，使用时查更新。 |
| 本土店、相邻任务 | [知无不言的店铺跟踪与差异化](https://www.wearesellers.com/question/120198)。 | 上新不等于销售；观察相邻方向后重新验证。 |
| 季节和趋势 | [Google Trends 指标解释](https://support.google.com/trends/answer/4365533?hl=en)。 | 同国家同窗口比较；注意相对值。 |
| 众筹 | [Kickstarter 产品设计](https://www.kickstarter.com/discover/categories/design/product%20design)、[支持与收款机制](https://updates.kickstarter.com/how-to-back-a-crowdfunding-project-on-kickstarter/)、[交付失败复盘](https://updates.kickstarter.com/why-kickstarter-campaigns-fail-after-funding-and-how-to-avoid-it/)、[Indiegogo 项目](https://www.indiegogo.com/en/projects/search)。 | 页面打不开不引用未读评论；支持、收款、交付分开。 |
| 成交价 | [eBay Product Research](https://www.ebay.com/help/selling/selling-tools/product-research?id=4853)。 | 同站点、成色、配件和运费口径对比，再核验 Amazon。 |
| 礼品、材质、风格与人群词 | [Etsy Marketplace Insights](https://help.etsy.com/hc/en-us/articles/35122361353239-How-Do-I-Use-Etsy-s-Marketplace-Insights-Tool)。 | Etsy 搜索和商品数不直接证明成交，更不代表 Amazon。 |
| 能展示的功能、内容需求 | [TikTok Top Ads](https://ads.tiktok.com/resources/help/article/how-to-use-the-top-ads-dashboard)、[TikTok Shop Product Insights](https://seller-us.tiktok.com/university/essay?knowledge_id=7067468817090317)、[小红书聚光搜索工具](https://ad.xiaohongshu.com/next_help/docs/d6e54d83d20628f893180ec49b790cbd)。 | 广告创意表现、平台订单、笔记互动分别记录。小红书用户地域和目标站点可能不同。 |
| 成本与测试 | [Amazon 收入计算器](https://sell.amazon.com/pricing/estimate)、[雨果跨境利润复盘](https://www.cifnews.com/article/188725)、[AMZ123 测品流程](https://www.amz123.com/t/GBZHeQ05)、[Amazon 内容实验](https://sell.amazon.com/tools/manage-your-experiments)。 | 第三方卖家经验不当作费率；AMZ123 此文由促销服务商发布，折扣测试不证明常价需求。 |
| 知识产权与安全入口 | [USPTO](https://www.uspto.gov/patents/search/patent-public-search)、[CPSC 企业指引](https://www.cpsc.gov/Business--Manufacturing/Business-Education)。 | 初筛来源，不以“未搜到”代替法律或合规结论。 |

## GitHub 与数据工具

- [研究策略卡](https://github.com/liangdabiao/amazon-sorftime-research-MCP-skill/blob/main/SKILLS/skills/sellersprite-amazon-research/README.md)：参考新品、关键词和评论流程。卡内阈值不覆盖用户标准。
- [PDBen 研究工作流](https://github.com/PDBen-Auto/amazon-product-research-agent-skills)：参考评论、可行性和决策分工；不因 README 声称能力就推定当前环境可用。
- [BERTopic](https://github.com/MaartenGr/BERTopic)：对已有、可使用的评论聚类；需要逐条回查，不把主题数当人群规模。
- [Amazon Reviews 2023](https://amazon-reviews-2023.github.io/)：可练习分类与去重，不代表当前市场。
- [Keepa Python 客户端](https://github.com/akaszynski/keepa)：历史数据工作流参考。开源代码不等于免费或已授权数据服务。

搜索时记录「查询词 → 读到的原页面 → 得到什么 → 下一步问题」。搜索结果摘要用于定位；查不到的正文、后台指标或付费字段记「未获取」，不得用教程中的演示数代替。
